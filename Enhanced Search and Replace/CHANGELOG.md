# 更新紀錄

## 1.0.0（2026-11-02）

- 首次正式發行，統一名稱為 Enhanced Search and Replace，新增專用工具列圖示與非模態搜尋視窗。
- 全書文字類型預設全選，可個別勾選；支援未儲存內容、Regex 原生群組及 `$1` 轉接。
- 新增純文字保格式／完整 HTML 片段取代；支援一般 XHTML DOCTYPE、標準實體、原位群組格式保留與 XML／JSON 完整性檢查。
- 即時更新預覽，支援標題全選、手動欄寬、單擊定位、逐筆下一筆及勾選批次；成功／失敗結果均保留。
- 單檔沿用 Editor Undo/Redo，跨檔使用書籍復原點及失敗回復；檢查過期結果並限制重複告警。
- 納入統一 build_release.py，附五組自動測試。calibre 9.17 離屏回歸通過；完整 GUI、保存重開及其他版本／平台尚未驗收，限制詳見 README。
