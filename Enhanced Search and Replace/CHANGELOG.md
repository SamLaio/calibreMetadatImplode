# 更新紀錄

## 1.1.0（2026-11-02）

- 由已發行 1.0.0 升為 1.1.0；外掛 README 新增使用者提供的完整操作截圖。
- 說明文字與檔案類型選單同列，左上角全選按鈕顯示文字。

- 預設結果區依字型與表頭高度配置十五行，視窗不超過螢幕可用高度，保留手動縮放。

- 全選／取消移至表格左上角按鈕，取消原生整格選取動作；勾選欄標題不再觸發全選或排序，保留其他欄位排序。

- HTML／XHTML 新增內文／原始碼搜尋，可搜尋標籤及屬性；原始碼取代仍驗證完整 XML。
- 搜尋移至背景工作，加入檔案進度、取消及關閉時的工作清理；取消保留已完成檔案的結果。
- 結果改用按需顯示的表格模型，新增狀態篩選與欄位升降冪排序，定位／取代依穩定來源對應；全選及批次僅處理可見列。
- 預覽分批更新，更新完成前禁止套用，改善大量結果的操作反應；大量取代改為一次組合來源並有效更新位置。
- Windows calibre 9.17 真實主視窗驗收：單筆、原始碼、跨檔批次、Undo/Redo、WebEngine 預覽、原生儲存、正常退出與新程序重開均通過。
- 新增背景／篩選／排序回歸，以及獨立程序的 GUI 儲存重開驗收。

## 1.0.0（2026-11-02）

- 首次正式發行，統一名稱為 Enhanced Search and Replace，新增專用工具列圖示與非模態搜尋視窗。
- 全書文字類型預設全選，可個別勾選；支援未儲存內容、Regex 原生群組及 `$1` 轉接。
- 新增純文字保格式／完整 HTML 片段取代；支援一般 XHTML DOCTYPE、標準實體、原位群組格式保留與 XML／JSON 完整性檢查。
- 即時更新預覽，支援標題全選、手動欄寬、單擊定位、逐筆下一筆及勾選批次；成功／失敗結果均保留。
- 單檔沿用 Editor Undo/Redo，跨檔使用書籍復原點及失敗回復；檢查過期結果並限制重複告警。
- 納入統一 build_release.py，附五組自動測試。calibre 9.17 離屏回歸通過；完整 GUI、保存重開及其他版本／平台尚未驗收，限制詳見 README。
