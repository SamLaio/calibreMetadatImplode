# Skip ASCII Text Plugin（保留原文字元）

本倉庫重寫版：**1.0.1（2026-11-01）**；作者：**SamLiao & Codex**；授權：GPL v3。最低 calibre 宣告為 **5.0.0**，本次實測環境為 Windows、calibre 9.17.0；未逐版驗證。

## 功用

讓使用 calibre 共用檔名轉寫功能的流程保留中文等原文字元，避免將「書店怪問」轉寫為 `Shu Dian Guai Wen`。這是執行期間的共用函式替換，不會改寫 calibre 安裝檔，也不會主動批次改名或修改電子書內容。

非法檔名字元仍交由 calibre 的後續流程清理，例如冒號或問號可能變成底線。是否影響特定書庫、儲存或傳輸操作，取決於該流程是否使用此共用函式；不能保證所有匯出與裝置都保留中文。

## 核心理念

**保留使用者原本的文字，以執行期間的函式替換達成，不直接修改 calibre 安裝檔。**

原版作者在 [Bilibili〈Calibre插件 Skip ASCII Text 解决中文名称保存问题〉](https://www.bilibili.com/opus/781451729027727384) 說明：受到 Hsuan 及走地雞文章中修改 `ascii_text()` 做法的啟發，改用外掛在執行期間替換函式，減少手動改核心檔案的步驟，以及升級 calibre 後重新修改安裝檔的需求。

本倉庫沿用這個功能方向，重新實作為：

- **原文字元優先**：保留中文等 Unicode 文字，不為了檔名轉成拼音；非法檔名字元仍由 calibre 後續清理。
- **執行期間套用**：只替換目前程序中的 `calibre.utils.filenames.ascii_text`，不改寫 calibre 安裝目錄。
- **可以停用與還原**：保存啟用前函式，只在本外掛仍持有替換時還原，避免整個模組重載或覆蓋後續外掛修改。
- **升級後重新套用**：由外掛在圖形介面初始化後啟用，不必每次升級都手動修改核心檔案；但 calibre 內部介面若改變，仍須重新驗證相容性。

前兩項是原文核心方向；文字型別處理、還原時的持有檢查與新版設定介面是本倉庫的實作。執行期間替換仍會影響使用同一共用函式的流程，不代表完全沒有副作用。

## 安裝與操作

1. 從 [v1.3.9 發行頁](https://github.com/SamLaio/calibreMetadatImplode/releases/tag/v1.3.9) 下載 `Skip ASCII Text Plugin` 安裝包；也可在本專案根目錄執行 `python -B build_release.py` 自行打包。
2. 在 calibre「偏好設定 → 外掛 → 從檔案載入外掛」選取下載的 ZIP；自行打包時選取 `dist/Skip ASCII Text Plugin-zh_TW-release.zip`。
3. 重新啟動 calibre；若工具列沒有按鈕，從「偏好設定 → 工具列與選單」加入「保留原文字元」。
4. 點選按鈕開啟「保留原文字元」設定視窗；外掛清單的自訂設定也使用同一視窗。勾選「啟用原文字元保留」後確認儲存，即時啟用；取消勾選並儲存則停用本外掛的替換。

視窗提供即時檔名效果示意，切換選項後按「儲存」才會套用；按「取消」保留原設定。視窗依字體尺寸配置，沒有額外的捲動框。

工具列提示顯示目前儲存的啟用狀態。全新設定預設啟用；已有舊版設定時沿用其開關，不會強制改成啟用。取消設定視窗不會儲存變更。

## 重寫版的處理方式

- 文字維持原文；位元組透過 calibre 的 `force_unicode()` 轉為文字，避免後續檔名清理遇到型別錯誤。
- 啟用前保存當時的函式，重複啟用不會把自己的替換當作還原目標。
- 停用時只還原本外掛目前持有的函式，不重新載入整個檔名模組。
- 如果其他外掛之後替換了同一函式，不會在停用時覆蓋它。
- 設定、按鈕與狀態提示使用正體中文，外掛識別名稱保留英文以相容舊安裝。

## 限制與還原

- 影響目前 calibre 圖形介面程序；獨立命令列程序不會因安裝此介面外掛而自動套用。
- 啟動前已發生的操作、預先保存舊函式參考的程式，以及其他工作程序，可能不受影響。
- 共用函式是程序範圍，無法只對單本書或單一裝置啟用。舊裝置若要求 ASCII 檔名，請先停用並測試。
- 不會自動將既有書庫路徑改回中文；不建議為了改名而刪書再匯入，應先備份並確認書目、閱讀紀錄及附件。
- 在外掛設定中停用可即時還原本外掛持有的替換。若從 calibre 外掛清單停用或移除整個外掛，請重新啟動 calibre，以清除目前程序的替換。
- 若其他外掛包裝或覆寫了同一函式，工具列顯示的是設定狀態，不代表能判斷整個呼叫鏈；變更相關外掛後請重新啟動驗證。

## 打包與驗證

使用本專案唯一打包入口，不需新增依賴：

```powershell
python -B build_release.py
$env:QT_QPA_PLATFORM = 'offscreen'
calibre-debug -e "Skip ASCII Text Plugin/tests/test_skip_ascii_text.py"
```

測試在獨立程序中執行，包含中文與位元組輸入、非法字元清理、重複切換、還原先前函式、保留後續外掛替換、初始停用、設定儲存與正體中文狀態，以及工具列設定連接；不會修改正在執行的 calibre 或使用者書庫。

本機 calibre 9.17.0 已通過上述 **10 組測試**，包含自訂設定視窗的儲存／取消與 20 點大字體排版檢查；另檢視了深色介面、12 點與 20 點字體的畫面。

安裝包位於 `dist/Skip ASCII Text Plugin-zh_TW-release.zip`。本版隨整合發行版 v1.3.9 發布；來源程式在 `src/`，測試在 `tests/`。本次未測試真實書庫匯入／匯出、裝置傳輸及所有舊版相容性。
