# calibreMetadatImplode

十個可獨立安裝的 calibre 外掛，包含正體中文介面與本倉庫修正。

**[下載 v1.3.9](https://github.com/SamLaio/calibreMetadatImplode/releases/tag/v1.3.9)**。點選外掛名稱查看安裝方式、版號、來源與修改紀錄。

| 外掛 | 用途 |
| --- | --- |
| [Skip ASCII Text Plugin](./Skip%20ASCII%20Text%20Plugin/README.md) | 保留檔名中的中文等原文字元，避免轉成拼音。 |
| [Extract ISBN](./Extract%20ISBN/README.md) | 從電子書內文擷取 ISBN，填入書庫。 |
| [Goodreads](./Goodreads/README.md) | 從 Goodreads 下載書籍資料與封面。 |
| [AZW6 Image Merge](./AZW6%20Image%20Merge/README.md) | 將 Amazon 隨附的高畫質圖片合併回主書檔。 |
| [Embed Metadata Safe](./Embed%20Metadata%20Safe/README.md) | 修正 EPUB 的特定中繼資料問題，再嵌入書庫資料。 |
| [Modify ePub](./Modify%20ePub/README.md) | 直接清理與修改 EPUB，免經轉檔。 |
| [Find Duplicates](./Find%20Duplicates/README.md) | 找出書庫中可能重複的書籍，供人工核對。 |
| [EpubSplit](./EpubSplit/README.md) | 按章節或目錄將 EPUB 拆成多本書。 |
| [Count Pages](./Count%20Pages/README.md) | 計算頁數、字數與可讀性統計。 |
| [Send to Kindle](./Send%20to%20Kindle/README.md) | 透過電子郵件寄書到 Kindle，可自訂寄送書名與檔名。 |
