# Extract ISBN（擷取 ISBN）

本倉庫修訂版：**1.6.6.1（2026-11-01）**，基於上游程式宣告版本 1.6.6。作者為 Grant Drake，授權為 GPL v3。

從電子書內文擷取 ISBN，經確認後更新 calibre 書庫中的 ISBN 識別碼；不會修改原始書檔，並保留其他識別碼。支援格式取決於 calibre 的輸入格式支援。

## 功用與適用情境

適合書庫缺少 ISBN，但電子書版權頁等內文含有 ISBN 的情況。它會找出號碼、驗證 ISBN-10 或 ISBN-13 的檢查碼，讓您確認後填入書庫；既有 ISBN 與擷取結果不同時，也可能被替換。

這個外掛不會上網查詢 ISBN 或自動下載書名、作者、封面。取得 ISBN 後，可另外使用 calibre 的中繼資料下載功能。號碼校驗通過也不代表一定對應到目前的版本。

## 安裝與使用

從 [v1.3.7 發行頁](https://github.com/SamLaio/calibreMetadatImplode/releases/tag/v1.3.7) 下載並安裝 `Extract ISBN-zh_TW-release.zip`，重新啟動 calibre。在「偏好設定 → 工具列與選單」加入「擷取 ISBN」，選取書籍後執行。使用正體中文介面時會載入 `zh_TW` 翻譯。

- 依 calibre 輸入格式偏好順序掃描，找到 ISBN 後停止嘗試其他格式。
- 非 PDF 先掃書前、再反向掃書尾，最後掃中間內容。
- PDF 不超過 15 頁時全掃；較長文件先掃前 10 頁，再反向掃最後 5 頁。
- 預設單本使用執行緒，多本使用背景工作程序，每批 100 本。
- 預設顯示結果並詢問是否套用，可從外掛設定調整。

## 本地修正

- 小寫 `x` 的 ISBN-10 檢查碼會先正規化為大寫，再進行校驗。
- 修正 PDF 書尾多掃一頁及未反向搜尋的問題。
- 修正沒有書籍格式時，錯誤摘要誤顯示為找不到 ISBN。
- 補齊 65 個正體中文介面字串，保留上游其他語系。
- 納入上游打包時使用的共用模組，所有程式位於 `src/`。

## 打包與驗證

在倉庫根目錄執行：

```powershell
python -B build_release.py
calibre-debug -e "Extract ISBN/tests/test_extract_isbn.py"
```

打包需要 `calibre-debug` 可由執行檔搜尋路徑找到，用 calibre 內建編譯器將 `.po` 翻譯編譯到 `dist/` 暫存目錄後放入 ZIP。原始碼不保存編譯產物；ZIP 排除 `.po`、隱藏檔與快取。

本機 calibre 9.17.0 已通過 9 組回歸測試，包含實際 EPUB、PDF 文字擷取、ISBN 校驗、掃描範圍與方向、錯誤摘要及安裝包翻譯檢查；另已核對 65 個介面字串均有正體中文翻譯、Python 語法與 ZIP 版本及內容。未進行圖形介面安裝與所有舊版相容性測試。

## 為什麼書裡有 ISBN，卻顯示找不到？

目前只掃描閱讀順序中的內文檔案，不讀取 EPUB 的 OPF 中繼資料，也沒有 OCR。以下情況可能找不到：

- ISBN 只存在 `content.opf` 的識別碼欄位，沒有出現在內文。
- 號碼放在圖片裡，或 PDF 沒有可擷取的文字層。
- 號碼被換行或 HTML 標籤拆開，或號碼本身未通過校驗。
- 號碼位於長 PDF 未掃描的中間頁面。

實際案例：《書店怪問》的 OPF 含有通過校驗的 `isbn:9789863610212`，內文則沒有找到 ISBN，因此外掛回報找不到。這是目前掃描範圍的限制，並非整個 EPUB 都沒有 ISBN；本版沒有加入讀取 OPF 的備援功能。OPF 的值也可能是先前由 calibre 嵌入，仍須核對版本。

若找不到，可查看電子書版權頁及書庫現有識別碼，再決定是否手動填入。掃描失敗不會清空既有 ISBN。

## 限制

ISBN 校驗僅確認號碼結構，無法辨認精裝、平裝或電子版。一本書有多個有效 ISBN 時仍須人工確認，建議保留套用前詢問。沒有 OCR，純影像 PDF 無法辨識；長 PDF 不搜尋中間頁面。部分跨行或被標籤拆開的號碼仍可能漏判。

最低 calibre 版本沿用上游宣告的 2.0.0，不代表已實測所有舊版。
