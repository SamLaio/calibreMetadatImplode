# Tag Cloud（標籤雲）

版本：**0.1.3**。作者：**SamLiao & Codex**。本倉庫自有外掛，無獨立上游；授權 GPL v3。

在 calibre 左側顯示可點選的標籤、系列或作者雲。標籤瀏覽器開啟時上下分割；關閉時詞雲使用整欄。兩者皆關閉時收起側欄。原標籤瀏覽器的搜尋／設定列保留在分類樹區塊底部，並與分類樹一起隱藏。

## 安裝與操作

1. 在「偏好設定 → 外掛 → 從檔案載入外掛」選擇 `TagCloud.zip`，重新啟動 calibre。
2. 使用底部面板切換列的雲朵圖示按鈕顯示／隱藏詞雲；原本標籤瀏覽器的按鈕獨立控制分類樹。上方工具列不提供標籤雲按鈕，舊配置會自動移除。
3. 字體大小依書籍數量縮放；滑鼠停留顯示完整標籤與本數。點選標籤立即篩選中央書單，再點一次取消。
4. 設定中的「點選動作」可選「交集」或「獨選」：交集累加多個詞且須全部符合；獨選只保留最新點選的一個詞，再點同一詞取消。從交集切到獨選時保留最後選取的詞。雲的篩選條件會與開始選取時的搜尋條件取交集；設定中的「清除目前選取」在搜尋列仍為雲產生的條件時還原原搜尋，保留手動改寫的搜尋。
5. 設定中可切換目前虛擬書庫／整個書庫，顯示前 50／100／200／500 個詞彙或全部。下方搜尋框可搜尋詞彙名稱，提供下拉歷史、左側紅叉清除及右側放大鏡／Enter 搜尋。統計不受目前搜尋影響，避免點選後雲的位置跳動。
6. 拖曳分隔線調整高度；顯示狀態、高度、統計範圍、數量與點選動作會保存。按重新整理圖示可重新統計。
7. 按齒輪圖示或在外掛偏好設定按「自訂外掛」，選擇統計欄位與字體配色。支援標籤、系列、作者及自訂多值文字／系列欄位；切換欄位會清除雲的選取。
8. 可啟用隨機配色並自行指定五個候選色，同一詞保持固定顏色；關閉隨機後統一使用第一色。設定按「確定」才保存。

## 限制

- 需要 calibre **9.19 或以上**；側欄嵌入使用 calibre 內部 Qt 介面，未來版本若改變分類樹結構可能需要調整。
- 採水平文字、取熱門前 N 個詞後亂序排列與自動換行；目前不含自由位置或旋轉文字的排版。
- 「整個書庫」只改變雲的統計範圍，中央結果仍遵守 calibre 目前啟用的虛擬書庫。
- 不修改書籍、書目或標籤，也不分析書籍內文。

搜尋框、重新整理與齒輪設定圖示排列在詞雲下方同一列，搜尋框占用剩餘寬度；不顯示標題與版號。

- **0.1.3（2026-11-27）**：底部獨立切換詞雲；依標籤瀏覽器狀態上下分割或獨占側欄，保存寬度與比例；移除上方工具列入口。數量選項改為 50／100／200／500／全部。

- **0.1.2（2026-11-27）**：欄位、範圍、數量、符合模式、數量摘要與清除選取移至設定；側欄保留搜尋與詞雲。

- **0.1.1（2026-11-27）**：字級依目前顯示詞彙的本數範圍縮放為 12～36 pt，行距縮至 115% 並移除段落留白；強化熱門程度差異；本數相同時統一為 20 pt。熱門前 N 個詞改採亂序顯示，同一次開啟期間保持位置。

- **0.1（2026-11-27）**：首次提供側欄詞雲、標籤／系列／作者與自訂欄位選擇、搜尋、多選交集／聯集篩書、範圍切換、可自訂隨機配色與版面設定保存。
