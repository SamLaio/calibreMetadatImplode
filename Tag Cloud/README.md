# Tag Cloud（標籤雲）

版本：**0.1.1**。作者：**SamLiao & Codex**。本倉庫自有外掛，無獨立上游；授權 GPL v3。

在 calibre 左側分類樹下方顯示可點選的標籤、系列或作者雲，與分類樹共用可上下拖曳的分隔線，底部原有搜尋工具保留。

## 安裝與操作

1. 在「偏好設定 → 外掛 → 從檔案載入外掛」選擇 `TagCloud.zip`，重新啟動 calibre。
2. 標籤雲預設顯示於左側；可用工具列「標籤雲」按鈕顯示／隱藏。若按鈕未出現，可在「偏好設定 → 工具列與選單」加入。
3. 字體大小依書籍數量縮放；滑鼠停留顯示完整標籤與本數。點選標籤立即篩選中央書單，再點一次取消。
4. 多選可切換「全部符合」或「任一符合」。雲的篩選條件會與開始選取時的搜尋條件取交集；「清除選取」在搜尋列仍為雲產生的條件時還原原搜尋，保留手動改寫的搜尋。
5. 可切換目前虛擬書庫／整個書庫、顯示前 40／60／100／200 個標籤，或搜尋標籤名稱。統計不受目前搜尋影響，避免點選後雲的位置跳動。
6. 拖曳分隔線調整高度；顯示狀態、高度、統計範圍、數量與符合模式會保存。按「更新」 可重新統計。
7. 按「設定」 或在外掛偏好設定按「自訂外掛」，選擇統計欄位與字體配色。支援標籤、系列、作者及自訂多值文字／系列欄位；切換欄位會清除雲的選取。
8. 可啟用隨機配色並自行指定五個候選色，同一詞保持固定顏色；關閉隨機後統一使用第一色。設定按「確定」才保存。

## 限制

- 需要 calibre **9.19 或以上**；側欄嵌入使用 calibre 內部 Qt 介面，未來版本若改變分類樹結構可能需要調整。
- 採水平文字、取熱門前 N 個詞後亂序排列與自動換行；0.1 不含自由位置或旋轉文字的排版。
- 「整個書庫」只改變雲的統計範圍，中央結果仍遵守 calibre 目前啟用的虛擬書庫。
- 不修改書籍、書目或標籤，也不分析書籍內文。
