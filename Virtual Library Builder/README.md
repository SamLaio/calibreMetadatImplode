# 書庫建立器（Virtual Library Builder）

版本：**0.1.12**。作者：**SamLiao & Codex**。本倉庫自有外掛，無獨立上游；授權 GPL v3。需要 calibre **9.19 或以上**。

建立及修改 calibre 原生虛擬書庫。保存篩選規則，符合條件的新書會自動收錄；不移動書籍、不修改書目。

![書庫建立器圖示](src/images/icon.png)

工具列及視窗使用兩層書架圖示：左半虛線、右半彩色實線。資料夾、安裝包與內部外掛識別維持 `Virtual Library Builder`／`VirtualLibraryBuilder.zip`，升級既有外掛即可。

## 安裝

從檔案載入 `VirtualLibraryBuilder.zip`，重新啟動 calibre，按工具列「書庫建立器」。若按鈕未顯示，到「偏好設定 → 工具列與選單」加入。可在 calibre 原生快捷鍵設定自行指定按鍵，預設留空。

預設視窗加高，簡易／進階模式共用同一編輯區，切換時不改變清單與按鈕位置；仍可手動拉伸視窗高度。

## 工具列下拉：條件篩選器

左下「建立書庫」可將目前條件另存為原生虛擬書庫：輸入 1～40 字名稱後建立，取消不寫入，同名不覆蓋。保存內容包含表格條件、AND／OR／取代組合後的原搜尋，以及目前虛擬書庫與附加限制；不必先套用搜尋。建立後視窗保持開啟，也不自動切換書庫或改寫搜尋列。

條件篩選器是非模態浮動視窗，開啟時仍可捲動、選取及操作 calibre 主書單；再次點選入口會帶回同一個視窗。

套用後視窗保持開啟，可繼續調整並再次套用；以開啟時的原搜尋作為組合基底，不會重複疊加上次條件。同一次執行期間，關閉後再開會還原該實體書庫上次的條件列、AND／OR 與套用方式（包含未套用草稿），不自動搜尋；重啟 calibre 後清空條件，不再讀取舊版的永久保存內容。若關閉期間原生搜尋已改動，則以新搜尋作為下一次組合的基底。

- 「清空條件」會重設條件列與組合方式；若原生搜尋仍是本視窗套用的結果，會還原套用前的搜尋。若搜尋已手動改寫則保留，不改變目前虛擬書庫。
- 按書庫圖示開啟原本的書庫建立器；按右側箭頭可選「開啟書庫建立器」或「條件篩選器」。兩者共用同一個外掛與條件元件。
- 條件篩選器使用相同的逐列 AND／OR、相對日期與比較功能；按「套用搜尋」直接更新 calibre 原生搜尋列，不建立或修改虛擬書庫。
- 可選與目前搜尋 AND／OR 組合，或取代搜尋式；套用前關閉不改變搜尋，套用後關閉保留已套用結果。保留目前套用的虛擬書庫範圍，結果仍由 calibre 原生搜尋顯示。
- 開啟後若切換實體書庫或搜尋列被其他操作改動，會停止套用，請重新開啟。

## 快速尋找與快捷鍵

工具列箭頭下拉新增「快速尋找」，與書庫建立器共用同一外掛。

- 預設「全部常用欄位」會搜尋作者、書名、系列、出版社、ISBN，以及目前書庫名稱含翻譯／譯者／translator／translate 的適用欄位；不假設每個書庫都有固定翻譯者欄位。
- 也可指定作者、書名、ISBN、系列、出版社或其他可搜尋的文字／系列／列舉欄位。未自動辨識的翻譯欄位仍可自行選取。
- 輸入文字後按 Enter 或「搜尋」，預設包含比對，可勾選精確比對。ISBN 可包含空白與連字號，指定 ISBN 時也支援部分號碼。
- 每次操作直接取代原生搜尋列，保留目前虛擬書庫範圍；不更動書目或建立虛擬書庫。視窗不阻擋主書單，搜尋後保持開啟。
- 在「快捷鍵設定…」開啟 calibre 原生快捷鍵設定，於「書庫建立器 → 快速尋找」自行指定按鍵，預設留空；快捷鍵只在 calibre 使用中生效，不是系統全域熱鍵。
- 再次呼叫會帶回同一個視窗，選取輸入框文字方便立即重查；切換實體書庫後會依新書庫重新讀取欄位。

## 新增或修改

- **新增**：左側選「＋新增虛擬書庫」，輸入名稱，設定條件，按「建立虛擬書庫」。
- **修改**：左側直接選既有書庫，調整載入的條件，按「儲存修改」。可同時調整名稱，不會另外建立副本；其他虛擬書庫保留。
- 任何單一書庫都可勾選「進階編輯條件（搜尋式）」，帶入目前表單條件後直接編輯。取消勾選時只有可完整還原的條件才轉回表單；複雜條件會保留原式並提示。
- 簡單條件會還原成欄位選項；含巢狀、正規表示式或無法可靠還原的既有條件，直接提供原始搜尋式編輯，保留其語法。
- 「預覽結果」可先查看符合本數及前 50 本書目，並非儲存的必要步驟。搜尋條件明細預設收起，可勾選顯示。
- 單一書庫按「建立／儲存修改」即儲存，不再詢問二次確認，也不彈出完成提示；名稱只有真的改動時才更名，同名仍阻擋覆蓋。關閉視窗而未儲存不寫入；切換其他書庫前若有未儲存修改，會詢問是否放棄。
- 目前選取的書庫若已被其他操作修改，會停止覆蓋，請重新開啟建立器。

名稱為 1～40 字且不能以 `*` 開頭。既有書庫可直接改名後儲存；遇到同名會阻擋，不覆蓋其他書庫。更名會保留分頁位置、隱藏狀態並同步目前套用的書庫。

## 移動排序

左側選擇既有書庫，按「↑ 上移／↓ 下移」。排列**立即保存**在目前實體書庫，並同步 calibre 原生虛擬書庫分頁；重開後保留。移動不影響右側尚未儲存的名稱或條件。「＋新增虛擬書庫」固定在最前面，第一項不能上移、最後一項不能下移；批次模式停用移動。

原生虛擬書庫下拉選單仍採 calibre 自身的名稱排序，本功能調整建立器清單與原生分頁，不改寫下拉選單行為。

## 進階條件產生器

勾選進階編輯後，搜尋式下方右側提供「條件產生器…」按鈕。

1. 選欄位、比較方式與值，可新增多條條件，每列選交集（AND）或聯集（OR），由上往下逐步與前面結果組合。
2. 文字可選等於、包含、不包含、不等於或正規表示式；日期可選固定日期、最近 N 天、N 天以前、今天、昨天、本月與今年。
3. 下方即時顯示產生的搜尋式，選擇以 AND／OR 與原式組合，或明確選擇取代整個搜尋式。
4. 按「帶回搜尋式」會先檢查搜尋式，再更新編輯區；取消保留原式。帶回不會直接寫入虛擬書庫，仍須按「儲存修改」。

例如加入日期選最近 30 天會產生 `date:>30_daysago`，使用 calibre 的語言獨立相對日期關鍵字，隨當日日期更新。詳見 [calibre 搜尋語法](https://manual.calibre-ebook.com/gui.html#search-interface)。

## 刪除虛擬書庫

左側選取既有書庫，按「刪除所選虛擬書庫」並確認。只移除該虛擬書庫設定，不刪除書籍或格式檔；取消不變更。刪除目前套用的書庫會解除限制，顯示全部書籍。其他虛擬書庫保留，新增或批次模式停用刪除。確認前後都會檢查目前實體書庫及所選條件是否被變更。

## 條件設定

- 主畫面與進階產生器共用相同條件表格，提供相同的比較、排除、正規表示式與相對日期功能。
- 每列前方選「交集 AND／聯集 OR」，第一列不需選擇。條件**由上往下逐步組合**：A、OR B、AND C 代表 `(A OR B) AND C`，不採隱含的運算優先序。主畫面即時顯示產生的搜尋式。
- 文字提供等於／包含／空白／非空白；日期、數字提供等於、大於／晚於、小於／早於及空白判定。
- 日期輸入 `YYYY-MM-DD`，評分為 0～5 星。是非欄位使用等於，輸入「是／否」；空值匹配遵守 calibre 是非搜尋設定。
- 欄位由目前書庫讀取，含標籤、作者、系列、出版社、格式及適用的自訂欄位。系統識別、路徑與不支援型別不列入。

## 批次建立

按「批次建立…」才展開此功能；按「返回單一書庫」回到編輯。

1. 選文字、系列或列舉欄位，勾選要各自建立書庫的值。
2. 可搜尋並「勾選可見項目」；隱藏項目原勾選保留，「取消全部勾選」清空全部。
3. 名稱範本預設 `{欄位}－{值}`，必須含 `{值}`；名稱超過 40 字時請縮短。
4. 同名預設跳過，可選自動加序號或確認更新條件。批次儲存前顯示預覽與建立／更新數量，再確認寫入。

多值欄位依書籍去重計數，同一本書可屬於多個虛擬書庫。所有預覽使用**整個實體書庫**，不受目前虛擬書庫或搜尋限制。勾選儲存後切換可立即前往結果，否則保留目前畫面；修改目前套用的書庫時原生結果會更新。

## 限制與驗證

- 表單支援逐列 AND／OR；其他巢狀分組可用原始搜尋式編輯。尚未提供固定手選書單與 Tag Cloud 右鍵整合。
- 大量欄位值的批次預覽可能需要等候。
- 通過 47 項隔離資料庫／Qt 測試，涵蓋快速尋找、ISBN、實際翻譯者欄位、條件組合、編輯與同名保護、篩選反覆套用、清空及同次執行記憶；另驗證實際安裝包的非模態主視窗操作、原生名稱對話框建立書庫，以及重啟清空條件。
- 驗證使用隔離測試書庫，尚未在使用者實際書庫測試。
