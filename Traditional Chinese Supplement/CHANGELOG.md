# 更新紀錄

## 1.1.1 — 2026-11-09

- 移除主介面與 Edit Book 的工具列／選單按鈕，保留自動補翻。
- 主介面在初始化完成後啟用；Edit Book 改在工具載入時啟用，不依賴按鈕建立。
- 舊版已加入的主介面動作隱藏；15 組自動化測試通過，含無按鈕時的啟用測試。
- 隨整合版 v1.3.17 發布。

## 1.1.0 — 2026-11-08

- 新增 317 條指定範圍對照及 12 條共用對照，補翻多個外掛的標籤、按鈕、群組標題及提示。
- 同一安裝包支援主介面及 Edit Book，保留修整書本與 KFX Input 專用處理。
- 保護一般下拉值、清單／表格與輸入欄；加入事件過濾器例外攔截，避免單一補翻錯誤逸出至 Qt。
- 14 組自動化測試及 13 個實際外掛面板測試通過，核對翻譯前後設定值與儲存結果。
- 隨整合版 v1.3.17 發布；未對使用者書庫回寫或驗收全部聯網／轉換功能。

## 1.0.0 — 2026-11-08

- 新增獨立正體中文補強外掛，於主介面初始化後啟用，監看指定視窗的顯示事件。
- 補齊 calibre「修整書本」八個漏翻選項、說明標題與下載外部資源說明。
- 補齊 KFX Input 2.34.2 設定視窗選項、三種完成通知選項與提示；保持索引與勾選值的原有意義。
- 僅處理已知英文原文，保留已有中文及未知字串；停用後重新啟動即可還原。
- 納入統一打包，通過七組測試；隨整合版 v1.3.17 發布。
